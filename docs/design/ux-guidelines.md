# Lineamientos UX

## Objetivo

Mantener experiencias claras, predecibles y consistentes entre módulos.

## Principios

- reducir carga cognitiva;
- priorizar tareas frecuentes;
- mantener navegación consistente;
- mostrar información suficiente sin saturar;
- dar retroalimentación inmediata a las acciones;
- prevenir errores antes de mostrarlos;
- permitir recuperación clara cuando ocurre un error.

## Formularios

- etiquetas visibles y comprensibles;
- marcar campos obligatorios;
- validar cerca del campo afectado;
- conservar información cuando una validación falla;
- no bloquear acciones sin explicar el motivo;
- organizar formularios largos por secciones lógicas.

## Tablas y listados

- encabezados claros;
- acciones consistentes;
- filtros visibles cuando aporten valor;
- paginación o carga progresiva según volumen;
- estados de vacío útiles;
- responsive behavior definido.

## Feedback del sistema

Toda acción relevante debe tener un estado comprensible: cargando, completado, error o acción requerida.

## Accesibilidad

Conservar contraste adecuado, navegación por teclado, foco visible, etiquetas semánticas y alternativas de texto cuando apliquen.

## Consistencia

Ante dos soluciones equivalentes, elegir la que ya esté establecida en el producto antes de introducir una nueva interacción.
