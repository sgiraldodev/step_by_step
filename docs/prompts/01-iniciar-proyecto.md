# Prompt estándar — Iniciar proyecto

Usa este prompt para comenzar un proyecto nuevo basado en este starter.

## Prompt

Quiero iniciar un nuevo proyecto usando este repositorio como base.

Antes de desarrollar código:

1. Lee `AGENTS.md` y la documentación vigente del repositorio.
2. Revisa arquitectura, stack, Design System, estrategia Git, testing, seguridad, operaciones y Definition of Done.
3. No cambies la arquitectura base salvo necesidad real; si se requiere una desviación relevante, propón un ADR antes de implementarla.
4. Ayúdame a completar primero Product Brief, requisitos, actores, alcance, reglas de negocio, módulos y dependencias.
5. Identifica qué capacidades opcionales aplican: multi-tenant, integraciones, almacenamiento externo, colas, etc.
6. Propón la primera vertical slice end-to-end que permita validar arquitectura, backend, frontend, base de datos, permisos, pruebas y Docker.
7. No implementes funcionalidades completas hasta que el contexto funcional mínimo esté claro.
8. Mantén toda la documentación del proyecto en español.

Entrega como resultado:
- Product Brief actualizado;
- requisitos iniciales;
- módulos propuestos;
- dependencias principales;
- riesgos y decisiones pendientes;
- plan de primera vertical slice;
- archivos de documentación que deban actualizarse.
