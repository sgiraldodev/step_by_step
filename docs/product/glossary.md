# Glosario

| Término | Definición |
|---|---|
| Tarea | Actividad puntual con título, prioridad, estado, ciclos y etiquetas. |
| Rutina | Definición repetible que genera un registro de tarea por día consultado mientras esté activa. |
| Ciclo | Bloque de trabajo resuelto explícitamente; suma una unidad aunque termine antes. |
| Esfuerzo | Segundos efectivos trabajados, excluyendo pausas y descansos. |
| Recibo | Registro durable con UUID de operación que evita duplicar esfuerzo/ciclos. |
| Espacio privado | Recursos de una cuenta, aislados por owner_id desde la sesión autenticada. |
| Código personal | Secreto entregado una vez para recuperar acceso; rota al restablecer contraseña. |
| Día de negocio | Fecha calculada en APP_TIMEZONE, America/Bogota por defecto. |
